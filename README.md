\# git-practice



我的 Git 练习场，记录 35 天 GitHub 学习之路的每一次提交。



> 学习原则：\*\*动手优先\*\*，一次提交只做一件事。



\## 学习进度



\- Day 1–3：账号、仓库、SSH ✅

\- Day 4–5：本地提交、push / pull / clone ✅

\- Day 6：标准节奏与提交规范 ✅

\- Day 7：gitignore 与 Markdown ✅



\## 常用命令



```powershell

git status

git diff

git add .

git commit -m "提交信息"

git push



```
